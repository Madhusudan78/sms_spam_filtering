# 📩 SMS Spam Filtering using Machine Learning

This project is a **Machine Learning based SMS Spam Detection System** that classifies messages as **Spam or Ham (Not Spam)**.  
The system analyzes SMS text using Natural Language Processing (NLP) techniques and predicts whether the message is spam or legitimate.

---

## 🚀 Features

- 📩 Detects spam and non-spam SMS messages
- 🤖 Uses Machine Learning algorithms
- 🧹 Text preprocessing using NLP techniques
- 📊 Data analysis and visualization
- 🧪 Model training and prediction using datasets

---

## 🛠 Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
